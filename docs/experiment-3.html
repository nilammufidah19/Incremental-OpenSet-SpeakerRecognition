4. Analisis singkat

  • Kenapa AS-Norm melompat +0.13 (bukan +0.01–0.03)? Efek dominan bukan di rejection tapi di identifikasi: term sisi-prototype menormalkan bias per-kelas jarak nearest-prototype (efek hubness pada 1-shot), argmin berubah → closed-set 0.732 → 0.865.
  • Catatan jujur: EER pada data kalibrasi justru naik dengan AS-Norm (0.219→0.256), tetapi deteksi pada task nyata membaik tajam (EER 0.170→0.111, AUROC 0.903→0.952). Target EER ≤ 0.15 tercapai pada metrik task, bukan pada proxy kalibrasi.
  • P5 terjawab: exp3a mengisolasi drift update pada threshold permisif (B1>B2); AS-Norm membuat gerbang update jauh lebih bersih → B2>B1 kembali, tanpa mekanisme margin tambahan.
  • Perbaikan insidental: bug kunci cache embedding (path relatif vs absolut) di precompute_embeddings.py; summary kini juga disimpan per-eksperimen (full_evaluation_summary_<tag>.json).
