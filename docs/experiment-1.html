Kenapa lapisan tengah Whisper? Lapisan akhir terspesialisasi ASR (konten/fonetik) dan menghapus identitas pembicara — divalidasi empiris: pooling lapisan akhir memberi kemiripan same-speaker lebih rendah dari different-speaker. Lapisan tengah mempertahankan lebih banyak sinyal speaker.

4. Arsitektur — Gated Attention Fusion

src/models/fusion.py, FUSION_DIM = 256.

e'_i = W_i · e_i + b_i (4.1) g = sigmoid(W_g · [e'_1 ; e'_2] + b_g) (4.2) e_fusion = g ⊙ e'_1 + (1 − g) ⊙ e'_2 (4.3) output = e_fusion / ‖e_fusion‖₂

Mode ablasi: fusion (A3, usulan) · ecapa_only (A1) · whisper_only (A2). Lapisan proyeksi identik antar-mode, mengisolasi kontribusi fusi.

4.1 Inisialisasi Residual (kontribusi Experiment 1)

Flag residual_init=True membuat output awal = ECAPA mentah:

  • proj_ecapa.weight = identitas parsial (blok 192×192 = I), bias 0 → e'₁ = [ECAPA;0].
  • gate.weight = 0, gate.bias = +4.0 → g = σ(4) ≈ 0.982 (dominasi ECAPA).
  • proj_whisper tetap random (trainable; A2 tak terpengaruh).

Verifikasi: fusi residual-init tanpa training = 0.783 closed-set = baseline ECAPA.

8. Evaluasi

FSCIL (src/evaluation/fscil.py): 10 sesi × 10 speaker baru (K_SHOT=1), tiap sesi menguji ulang query semua task sebelumnya (n_query=5). Query benar bila is_known & prediksi tepat. Metrik: Average Accuracy (3.14), Forgetting Measure (3.15). N_REPS=5, seed [0..4]. Uji: Shapiro-Wilk → paired t-test/Wilcoxon, Bonferroni α=0.05/6=0.00833.

10. Analisis

10.1 Dekomposisi kesalahan

scripts/diagnose_accuracy_gap.py memecah error menjadi confusion (prototype terdekat = speaker lain, ~66.9%) vs false-reject (benar tapi ditolak threshold, ~16.4%). Confusion mendominasi → masalahnya kualitas embedding, bukan penalti open-set.

Monoton menurun. Makin banyak training makin buruk. 71 speaker terlalu sedikit untuk memperbaiki ECAPA yang sudah pretrained penuh — training hanya overfit & merusaknya. Karena itu Experiment 1 membekukan fusi.

10.3 Temuan penting

  1. Membekukan menang telak: usulan 0.235 → 0.731; mengalahkan ProtoNet, x-vector, Whisper-saja secara signifikan; hanya tertinggal tipis dari ECAPA closed-set (0.788).
  2. Forgetting hampir nol (0.0004) vs ECAPA 0.053, ProtoNet 0.121 — keunggulan kerangka continual.
  3. Continual update terbukti membantu: B2 (0.731) > B1 (0.666), p=0.0037.
Keterbatasan (harus disebut jujur). Karena gate condong ke ECAPA (~0.98) dan fusi dibekukan, A3 ≈ A1 (identik, p=1.0) — kontribusi fusi Whisper belum terbukti pada skala ini. Nilai yang terbukti adalah kerangka open-set + continual. Membuktikan fusi menambah nilai butuh base training skala penuh (VoxCeleb2 penuh) → kerja lanjutan (Experiment 2+).
