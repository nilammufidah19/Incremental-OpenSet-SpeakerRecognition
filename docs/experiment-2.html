Kesimpulan Experiment 2. Score-level fusion + Whisper-L4 tidak mengungguli Experiment 1 (0.733 ≈ 0.731). Plafon komplementaritas Whisper kecil (+4% oracle) dan kontribusinya pada metrik open-set ~0. Lever sesungguhnya untuk melampaui baseline adalah THRESHOLD, bukan fusi — memicu Experiment 3.

1. Motivasi — gap dari Experiment 1

  1. Kontribusi fusi Whisper = 0 (gate ~0.98 → A3 ≡ A1, p=1.0).
  2. Belum melampaui baseline ECAPA closed-set (0.788).

Tujuan: membuat kontribusi Whisper terukur — tanpa menaikkan shot, tanpa fine-tuning yang merusak.

2. Yang diimplementasikan (2a)

a. Fitur Whisper → lapisan 4 (bukan tengah/L3), di-cache terpisah sebagai backbone whisper_l4 (layer_fraction = 4/6).

b. Fusi → score-level: keputusan di level jarak, skor = w·d_ecapa + (1−w)·d_whisper (w=0.4). Direalisasikan tanpa mesin baru lewat konkatenasi berbobot (ekuivalen, diverifikasi eksak):

out = [ √w · ê_ecapa ; √(1−w) · ê_whisper ] ‖Δout‖² = 2·( w·cosdist_ecapa + (1−w)·cosdist_whisper ) ← persis score fusion

Modul ScoreFusionEmbed (bebas-parameter) menggantikan GatedAttentionFusion, sehingga sistem prototype-distance, kalibrasi, dan harness FSCIL berjalan tanpa perubahan. Ablasi memetakan ke bobot: ecapa_only→w=1, whisper_only→w=0, fusion→w=0.4.

5. Dua masalah yang terungkap

5.1 Artefak threshold pada ablasi

Threshold dikalibrasi pada A3 (w=0.4) lalu dipakai bersama A1/A2. Karena score-fusion mengubah skala jarak per-w, threshold salah untuk A1 (w=1.0) → anjlok 0.069 (artefak, bukan embedding). Perbaikan: kalibrasi per-konfigurasi. Tidak memengaruhi angka A3.

5.2 Threshold EER = sumber kerugian utama

Sweep bobot dengan threshold dikalibrasi ulang per-w, tiga regime (3 seed):

  • open@p95 ≈ closed → threshold permisif (persentil-95 genuine, ~5% false-reject) menghilangkan hampir seluruh penalti open-set; EER menolak terlalu banyak genuine.
  • Metrik FSCIL tidak punya query unknown → setiap penolakan = false-reject murni; EER (menyeimbangkan FAR=FRR) adalah titik operasi yang salah untuk metrik ini.
  • Whisper marginal: w=0.6 terbaik hanya +0.004 vs ECAPA murni.
→ memicu Experiment 3 (fokus threshold).

6. Analisis & kesimpulan

  1. Whisper bukan jalan menembus baseline — plafon kecil, kontribusi open-set ~0.
  2. Threshold adalah lever nyata — EER menghukum sistem tanpa manfaat pada metrik tanpa-unknown; titik operasi low-FRR (p95) memulihkan hampir semua kerugian.
  3. Forgetting tetap ~0, continual tetap membantu (B2 > B1) — kekuatan kerangka bertahan.
Rekomendasi Experiment 3: (a) titik operasi EER → low-FRR (calibration_target_frr), (b) laporkan akurasi closed-set berdampingan (apple-to-apple dengan baseline), (c) opsional AS-Norm menurunkan EER 0.22. Peluang paling nyata menyamai/melampaui baseline.
